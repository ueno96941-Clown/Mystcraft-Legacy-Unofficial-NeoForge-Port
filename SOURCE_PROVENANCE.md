# Source and Asset Provenance

**Release baseline:** `0.13.7.06-port.1.0.0-Ueno` / 2026-09-26

## Mystcraft upstream baseline

The redistribution/source comparison baseline is the official public Mystcraft Legacy repository:

- repository: `https://github.com/Mystcraft/Mystcraft-Legacy`
- branch used during porting: `1.12/develop`
- pinned commit: `9bc8ddc061845df0cd5ea47f4fdef773cff786ae`
- behavior target: Mystcraft `0.13.7.06`
- license file at that pinned source baseline: GNU LGPL version 3

The historical CurseForge binary was used only as a private behavior/reference input. It is not redistributed in the public source package or mod JAR.

## Port source

The Java/resources under this release are the modified 1.21.1/NeoForge port. `MODIFICATION_NOTICE.md` describes the major modification areas. Minecraft, NeoForge, JEI, Parchment and Gradle are external build/runtime dependencies and are not copied into the public source as project binaries.

## PNG/OGG asset verification

`ASSET_PROVENANCE_SHA256.tsv` records every PNG/OGG shipped under `src/main/resources/assets/mystcraft` in this release.

- total audited PNG/OGG files: **120**
- byte-identical to at least one file in the pinned official Mystcraft-Legacy source baseline: **119**
- port-added compatibility asset: **1**, `textures/item/white.png`

The restored Decay textures are byte-identical to their matching upstream files. Some identical upstream textures are intentionally duplicated or relocated under modern atlas-safe paths; the table records matching upstream paths by SHA-256.

The eight shipped OGG files are Mystcraft-named linking/meteor effects and are byte-identical to files in the pinned Mystcraft-Legacy source baseline. No Myst/Riven game music track, official game executable, game-data archive, or Cyan marketing artwork was identified in the audited release package. This is a package-content observation, not a legal authorship determination.

## Generated Archivist structure

`src/main/resources/data/mystcraft/structure/village/archivist_house.nbt` is generated by `tools/generate_archivist_house.py` as a modern structure representation of the upstream Mystcraft Archivist-house geometry/behavior. It references ordinary Minecraft resource identifiers but is not a copied vanilla structure-template file.

## Public-export boundary

The public exporter removes caches/build outputs, run/log/crash data, internal checkpoint/history documents, development-only harnesses, patch/ZIP/class artifacts, embedded Gradle distributions, non-wrapper JARs, and private comparison material. See `PUBLIC_RELEASE_EXCLUDES.md`.
