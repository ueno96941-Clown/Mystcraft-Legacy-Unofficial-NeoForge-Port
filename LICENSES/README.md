# License-text directory

This directory is intentionally broader than the project's primary license so the public source archive carries the texts relevant to redistributed build-wrapper material and clearly documents external development dependencies.

- `LGPL-3.0.txt` — primary Mystcraft/Mystcraft-Legacy port license text (same text as root `LICENSE`).
- `GPL-3.0.txt` — GPLv3 terms incorporated/referenced by LGPLv3 and included defensively with binary/source distributions.
- `Apache-2.0.txt` — applies to Gradle wrapper scripts and the optional official wrapper JAR restored by `bootstrap_wrapper.ps1`.
- `LGPL-2.1.txt` — reference copy for externally fetched NeoForge/ModDevGradle; their binaries are not bundled in this public source export.
- `CC0-1.0.txt` — reference copy for externally fetched Parchment mappings; mapping artifacts are not bundled as project-owned assets.

Including a third-party license text here does not change the license of unrelated files.
